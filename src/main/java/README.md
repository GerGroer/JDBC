# Лабораторная работа: Работа с базами данных в Java (JDBC)
**Автор:** Нарольский Максим Витальевич  
**Группа:** Фит 251

## Описание
Работа с реляционной базой данных (H2) из Java с использованием JDBC. В рамках работы выполняются SQL-запросы на выборку, фильтрацию, сортировку и модификацию данных в таблице `study.music`, а также парсинг JSON-файла с посетителями и книгами через библиотеку Gson с последующей загрузкой уникальных записей в нормализованные таблицы базы данных.

## Стек технологий
* **JDK 25**
* **Maven**
* **H2 Database** (встроенная СУБД в памяти)
* **Gson** (чтение и парсинг JSON)

## Сборка и запуск
Для сборки и запуска проекта требуются установленные JDK 25 и Maven. Файлы ресурсов (`music-create.sql` и `book.json` / `books.json`) находятся в директории `src/main/resources`.

```bash
mvn compile
mvn exec:java
```
